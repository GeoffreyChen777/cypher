# Cypher 0.3.44 — Long work runs stay short again

## Chats

- **"Tool calls shown per group" bounds a long work run again.** Since
  thinking between tool calls folded into one work run, the run's calls sat
  in small groups split by its thoughts, each well under the limit, so a
  long run showed every call. An open run now applies the limit as a whole:
  it keeps its last calls and the thinking around them, and folds the rest
  behind one row ("Show 4 earlier tool calls and 2 thoughts") that reveals
  the whole run and folds it back. Thoughts don't count toward the limit,
  and changing the setting applies straight away.

macOS only, at build 1: the change is in the desktop UI, which the headless
Linux build doesn't include, so Linux stays on 0.3.43. Pi Runtime stays at
1.0.1.3; iOS stays at 0.2.0 (25).
