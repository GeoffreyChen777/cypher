# Cypher 0.4.8 — a workspace chat you can work in, code that reads like prose, and pushes that arrive

## Workspaces

- **The workspace chat has the side panel.** Files, Git and the terminal now
  open beside a workspace's own chat, as they do beside a session. Files and
  Git can show the workspace's folder or any project it may see; a picker in
  their header switches between them.
- **File references in a workspace chat open.** A path the agent cites is
  looked up in the workspace's folder, then in each project it may see, and
  opens in Files at its line. Hovering shows a preview. A path outside all of
  them doesn't open.
- **No more empty plan cards.** When a plan was too long, the agent's first
  attempts were refused, but each still drew a card saying "This plan is no
  longer available" before the real one. A refused attempt now shows as a
  failed step, in old chats too. The plan's limits are stated to the agent up
  front, so it rarely goes over.
- **Longer plan steps.** The 1,500-character limit per step is gone; only the
  4,000 across the whole plan remains.

## Chats

- **Code reads like part of the sentence.** Inline code and file names are
  set a step smaller than the text (0.86×), in the text's own colour on a
  neutral background, so a line with code is as tall as one without. File
  references are neutral chips with a file icon and a hairline. They select,
  copy, find and stream like the words around them.

## Phone

- **Pushes when a workspace needs you.** A workspace asking you something in
  its own chat, a plan waiting for approval, an action to approve, a hidden
  plan or routine thread with a question, and an answer to review now reach
  the phone. Tapping one opens the workspace's chat, or the item on its board.
  The server side is already live; opening the item needs this build.
- **Shortcuts send with their text left empty**, as on the desktop. An empty
  blank is removed cleanly from the request on both.
- **Long tool runs fold.** A group of tool calls shows its last five and
  folds the earlier ones.
- **Models load again after the Mac relinks.** A relay link that stops
  answering is replaced, and a failed model list says why instead of
  "Couldn't load models".

## Hosts

- **A replaced host connection ends its clients' links** so they redial at
  once, and models listed before discovery finished are kept.

Cut at build 1 on macOS and Linux, with iOS 0.4.0 (49) for TestFlight. Pi
Runtime stays at 1.5.2.4. A workspace gets the new chat panel and pushes once
the device hosting it runs 0.4.8.
