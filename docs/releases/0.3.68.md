# Cypher 0.3.68 — Pair Linux devices

## Linux

- **Pair a Linux device with your other devices.** Pairing lived only in
  Settings → Devices, which a headless Linux device doesn't have, and the
  desktop can't pair another device remotely, so Linux devices stayed
  Not paired. Three commands bring it to the terminal:
  - `cypher pair` shows whether this device is paired, its key, the
    paired devices and the Only paired devices policy.
  - `cypher pair join <code>` joins with the code a paired device shows
    under Add a device, then waits for that device to approve it.
  - `cypher pair add` shows a code for a new device, then shows the
    device that entered it, with its key, and asks before adding it. A
    Linux device set up before your desktop founded the group itself;
    this is how it adds the desktop.
  - Ctrl-C cancels either side. `cypher status` shows a Pairing line, and
    setup's last step points at `cypher pair`.

## Desktop

- Settings → Devices → Pairing names the Linux commands next to the code
  it shows and in the steps for joining. This ships with the next macOS
  release.
