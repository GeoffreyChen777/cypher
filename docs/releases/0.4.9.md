# Cypher 0.4.9 — previews in chat, permissions that ask less, and plans that never stall silently

## Chats

- **Pictures and files show in the reply.** An image the agent links or
  cites, a screenshot a tool read or wrote, an SVG, the pages of a PDF, a
  video's first frame, a CSV or TSV as a table, and a local HTML page as a
  card that opens in the viewer. Every preview is as wide as the reply; a
  tall one is cut to 4:5 and opens whole on a click; a PDF's pages sit side
  by side. A caption is said once. Links to web pages are never fetched for
  a preview, and an https image that redirects to plain http is refused.
- **Commits, pull requests and issues are links.** A commit's short hash and
  a `#123` in a reply link to them; hovering shows a card with the title,
  state and author. Commits come from the project's own git; pull requests
  and issues from GitHub, with the sign-in you already have. A reference that
  names nothing turns back into plain text.
- **A message that starts with "/" is a command only when it names one.** A
  pasted path like `/Users/…` is an ordinary message again.
- **Extension notices are not replies.** Claude's usage warnings ("rate limit
  warning: 57% used") show as a quiet status line instead of landing in the
  reply, or as a plan's result.
- **A chat no longer gets stuck on "Session boundary … is absent from the
  transcript".** Stopping a Claude run could leave a cut-off transcript that
  every later turn tripped over. The cleanup now waits for Claude to finish
  writing, and a transcript that doesn't fit is rebuilt from the chat's
  history.

## Permissions

- **Far fewer questions about work you asked for.** What your latest
  messages asked for passes; only a small floor always asks: a secret
  leaving the machine, and changes to the permission rules themselves. A
  decision you denied stays denied for the same action.
- **Each plan has its own permission level.** The card offers the
  workspace's default, or what you asked for in your own words, quoted.
  You can change it while the plan runs, and it applies at once. Full
  access still keeps the floor.

## Workspaces

- **A plan's questions always reach Needs you.** A permission prompt or a
  question from any session a plan started or steered, or a subagent under
  one, shows in Needs you with its step marked Asking, and sends one push.
  It survives a restart; when its device is offline it says "Waiting for its
  device" instead of disappearing.
- **Plans can be longer.** A plan's step details may add up to 30,000
  characters (was 4,000), and its result to 30,000. The card and the list
  keep a short preview; the plan's page shows the full text. A plan over the
  limit is refused with how much it is over; nothing is cut without a word.
  Until the device hosting a workspace runs 0.4.9 its plans keep the old
  limits.
- **Long texts are refused, not cut.** A routine's prompt or a shortcut's
  request over 4,000 characters, and an edited answer to review over 8,000,
  used to be cut short silently. Now you are told how much it is over and
  your text is kept.
- **Switching workspaces keeps each one's side panel.** Files, Git and the
  terminal come back as you left them, also after a restart.

## Phone

- **Needs you looks like iOS.** One card per item in grouped sections; every
  choice of a permission prompt (Stop, Deny, Always, This chat, Run once) is
  a visible button, and every decision button has the same height.
- **The same previews as on the desktop**, with tables, PDF pages, video
  frames and pull request cards.
- **Comments on a message show above it**, quote and comment, as on the
  desktop.

## Behind the scenes

- **Much less background traffic.** The device trust list is pushed when it
  changes instead of fetched every minute, a workspace's messages from other
  workspaces arrive on a nudge, a reconnect no longer fetches the same rows
  twice, and an offline device is dialled less and less often. In our
  measurements an idle device makes about 85% fewer requests.
