# Cypher 0.3.13 — Claude and ChatGPT subscription sign-in

- Settings → Providers can sign in to Claude Pro/Max and ChatGPT Plus/Pro (Codex) using Pi's OAuth, stored in that device's Runtime `auth.json`.
- Sign-in runs on the selected host with a paste-callback or device-code handoff, so local and remote devices both work.
- OpenAI-compatible / NewAPI API-key providers are unchanged.
