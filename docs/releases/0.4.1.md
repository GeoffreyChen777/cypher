# Cypher 0.4.1 — A workspace chat with a session's tools

## Workspaces

- **MCP servers work in the workspace chat.** It warned that "MCP tools
  are only reachable from the codemode or tool_search tool, but neither
  is active; they cannot be called." It now reaches your MCP servers the
  way a session does: from scripts, or by loading the tools it needs.
- **Web search and questions.** The workspace chat can search the web,
  and ask you a question with options, answered in the chat like a
  session's.
- **`/scripts` works there too**, turning scripts off and on as in a
  session; with them off, MCP tools are still found through tool search.
- These are the workspace's own chat only. Routines, the threads that
  carry out plans and the answers to other people's workspaces run
  without anyone watching, or for someone else, so they get none of
  them, and no longer connect to MCP servers at all.
- After a web search or an MCP call, what the agent saves to memory
  still waits for your OK first, including calls made from a script.
- The workspace's host device needs 0.4.1 for these.

Cut at build 1 on both desktop platforms. iOS stays at 0.4.0 (44) and Pi
Runtime at 1.5.2.1.
