# Cypher 0.3.43 — Thinking and tool calls fold into one row

## Chats

- **A reply that thinks between commands reads as one row.** A reply that
  alternated thinking and tool calls used to show a column of "Thought" and
  "Ran N commands" toggles. A run of tool calls and thinking with nothing
  else in between now sits behind one toggle that sums it up, such as "Ran 3
  commands · 2 thoughts · 1 failed". Opened, it shows the run in order: each
  tool chip, and each thought as a lightbulb chip labelled with its first
  line, its text still folded underneath. The toggle stays open while the
  run is still streaming and closes once the answer starts. A run of only
  tool calls, or a single thought, looks as before.
- **Toggles stay the way you leave them.** A toggle that starts open, like a
  streaming tool group, can now be closed and stays closed.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.0.1.3; iOS
moves to 0.2.0 (25) with the same change.
