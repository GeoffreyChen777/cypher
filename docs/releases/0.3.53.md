# Cypher 0.3.53 — Context recovery, and still water on the new-session canvas

## Chats

- **Restart a failed turn with added context.** When a watched Pi chat's
  round ends with an answer or error containing a phrase you configured,
  the host asks a model you choose for supplementary context, rewinds the
  chat to just before the prompt that failed, and sends that prompt again
  with the context ahead of it. The failure leaves both the transcript and
  the agent's memory. Set it up in Settings → Agents → Context recovery:
  the watched models, the model that writes the context, the trigger
  phrases, the instruction, and how many attempts one message gets (1–3).
  A message that keeps failing stops at the limit, and every retry starts
  from your own words. If any step can't go ahead, the failed turn is left
  exactly as it was.
- **See what a recovery did.** A resent prompt is captioned "Restarted
  with context"; hovering it shows the restart point, the matched phrase
  and the added context. While a recovery runs, a spinner under the failed
  reply says so, on every device watching the chat.

## New session

- **The new-session canvas ripples under the pointer.** Moving the pointer
  over the canvas drags a wake of text characters through still water that
  spreads, crosses and settles back to nothing. Still water draws nothing,
  and Reduce Motion keeps it still.
