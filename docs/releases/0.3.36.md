# Cypher 0.3.36 — Honest thinking levels, and tidier tiles

## Models

- **Pi models offer only the thinking levels they support.** Every Pi model
  that could reason listed the full Minimal–Max ladder, but Pi quietly
  swapped an unsupported level for a neighbouring one, so some picks never
  ran as chosen and a swapped X-High could fail the run. The picker now shows
  each model's real levels, models that can't think no longer offer any, and
  the subagent editor narrows its levels to the chosen model.

## Workspace

- **The Traits chip stops flickering in narrow tiles.** In a compact
  composer the chip could show and hide every frame; it now settles.
- **Dock buttons stay clear of the session rail.** While a tile shows its
  rail, the Git and Files control rows and the side chat's selection bar
  leave room for it, so the rail no longer covers their buttons.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.3; iOS
stays at 0.2.0 (19).
