# Cypher 0.3.60 — A file manager, math in chat, and progress for long turns

## Files

- **Files is a file manager.** The tree could only browse and edit text.
  It now manages the session's checkout, on whichever device hosts it:
  - Select several rows (⌘-click, ⇧-click) and drive the tree from the
    keyboard: arrows, ⏎ to open, F2 to rename, ⌘C/⌘X/⌘V, ⌘D to
    duplicate, ⌘⌫ to move to the Trash.
  - The context menu adds new files and folders, renaming in place, Copy
    Path, Reveal in Finder, Open with Default App and Mention in Chat.
  - Drag rows to move them (hold ⌥ to copy), and drop or paste files from
    Finder to import them. Nothing already there is ever replaced: copies
    become "name copy", imports "name 2". Deletes ask first.
  - A go-to-file field above the tree searches the whole checkout.
  - Uncommitted files carry git marks, and the tree refreshes when the
    agent changes files.
  - Images, SVG and Markdown preview. Other binary files show an info
    card and a hex view.
  - Drag the divider between the tree and the file to resize it.
  A host still on an older Cypher can browse but reports that it needs an
  update for the rest.
- **⌘S saves in the Files editor.** It used to toggle the sidebar.

## Chats

- **Math renders.** `$…$` and `\(…\)` set inline, `$$…$$` and `\[…\]` as a
  centered display formula, in the text color. Copying a formula copies
  its TeX. TeX that doesn't typeset shows as code, and prices and code
  keep their dollar signs.
- **Long turns show a progress bar.** After a turn has run for a minute, a
  small model from the run's own provider estimates how far it has got,
  every half minute: a percentage, what the agent is doing now, and the
  steps still to come, revised as the agent learns more. Hover a dot for
  its step; hover the current one for every step ahead. Each reading is
  one short request on that provider, and there is no setting to turn it
  off. Side chats don't get readings; subagent chats do. A reading that
  fails is skipped and never touches the run.

## Web search (with Pi Runtime 1.1.0.11)

- **Claude models can search with Claude Code's own web search.** Claude
  Code models couldn't search, so `web_search` in a Claude chat always went
  through another provider's model. In Settings → Providers → Claude →
  Manage you can
  now pin a Claude model for search. Each search runs as a separate Claude
  Code query that can only search: it doesn't touch the conversation's
  session or anything in `~/.claude`. Automatic still never picks Claude
  Code. Claude models show up there once the device's Runtime is 1.1.0.11.

## Permissions (with Pi Runtime 1.1.0.11)

- **Copies to one machine are local work.** `scp` and `rsync` to or from a
  single host are approved like `ssh` to it, and remembered per host.
  Copying between two machines, copying local secrets or startup files,
  `rsync --delete` to a remote, and `rsync -e` or `--log-file` still ask
  you every task.
- A variable set to a literal earlier in the line is read as its value,
  and `ssh` rules ignore options that change nothing locally (such as
  `ConnectTimeout` or `BatchMode`).

## Notifications

- **Every question in a turn notifies.** A turn that asked several
  questions or permission requests sent a notification for the first one
  only. Each new one now notifies once it is asked after you answered the
  last. This is a server change: it reaches every device without an
  update.

## iOS 0.2.0 (34)

- **Math renders**, as on the desktop: inline and display formulas in the
  text color, with display formulas shrinking to fit. Copying, Comment and
  Side Chat quote a formula as its TeX.
