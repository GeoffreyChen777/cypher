# Cypher 0.3.12 — durable Chat2 write coalescing

- Coalesce causal local Chat2 updates into a two-second durable push window.
- Force durable flushes at completed, failed, steered, interrupted, and input boundaries.
- Persist an outbox before sending and retire only the acknowledged batch in the same snapshot/cursor transaction.
- Restore pending outbox updates after restart without advancing the cloud cursor.
- Preserve payload immutability for restored or in-flight batch IDs and fail closed when causal history is incomplete.
