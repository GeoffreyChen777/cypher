# Cypher 0.4.5 — Routines that wait for approval

## Workspaces

- **Routines wait instead of failing at an approval.** Both scheduled and
  manual runs can pause for your decision, whether they run in a workspace
  or a project. Previously, even Run now was treated as unattended and
  stopped as soon as a command needed permission.
- **Find the decision in Needs you.** Open the routine's question or
  permission request there, approve or deny it, and the same run continues.
  The routine's Last run shows **Needs you** while it waits, on desktop and iOS.
- **No automatic permission grants.** Sandbox and permission rules are
  unchanged. Later scheduled slots are skipped while a run waits, so a
  pending approval does not start overlapping runs. Stopping the run clears
  its pending question.

Update the device hosting the routine to 0.4.5, and the devices used to
answer to this desktop release or iOS 0.4.0 (46). Previously failed runs
are not retried automatically; run them again when ready.
