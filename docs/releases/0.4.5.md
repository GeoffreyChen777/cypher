# Cypher 0.4.5 — Devin, and routines that wait for approval

## Providers

- **Devin.** Settings → Providers lists **Devin** next to ChatGPT. Sign in
  with your Devin account: open the sign-in page, then paste the one-time
  code it shows. This also works for a device you reach remotely. Devin
  models then appear in the model picker, and `/devin` shows your quota.
  Devin support comes from the unofficial `@buyong/pi-devin` package, which
  uses Devin's private CLI APIs. Cognition may change those APIs at any
  time, and your Devin account's terms apply. The package stays off until
  you sign in to Devin, so nobody else pays its startup cost.

## Workspaces

- **Routines wait instead of failing at an approval.** Both scheduled and
  manual runs can pause for your decision, whether they run in a workspace
  or a project. Previously, even Run now was treated as unattended and
  stopped as soon as a command needed permission.
- **Find the decision in Needs you.** Open the routine's question or
  permission request there, approve or deny it, and the same run continues.
  The routine's Last run shows **Needs you** while it waits, on desktop and
  iOS.
- **No automatic permission grants.** Sandbox and permission rules are
  unchanged. Later scheduled slots are skipped while a run waits, so a
  pending approval does not start overlapping runs. Stopping the run clears
  its pending question. Previously failed runs are not retried
  automatically; run them again when ready.

## Memory

- **Memory saves without asking.** Agents decide what to remember and save
  it, instead of holding the write for your approval. A save made after a
  run read web, search or MCP content is marked with what the run read, and
  the next consolidation pass checks those changes first. After another
  workspace's answer, a run's memory is read-only. Writes still held by
  earlier versions can be saved or dismissed as before.

## Notifications

- **New chimes.** Done and Needs you have new, softer sounds.
- **Only your own sessions make a sound.** Subagents, memory passes,
  hidden bot threads and archived sessions finish silently.

## Fixes

- **The engine no longer freezes under "Only paired devices".** Opening
  many sessions at once, as a workspace plan does, could lock the engine
  until the app was quit.

Cut at build 1 on macOS and Linux, with iOS 0.4.0 (46) for TestFlight.
Pi Runtime 1.5.2.2 adds the Devin package and needs Cypher 0.4.5.
