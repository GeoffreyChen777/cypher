# Cypher 0.3.14 — About, updates, and provider polish

- Add **About Cypher** and **Check for Updates…** to the app menu. About shows the running version and install kind; Check for Updates queries the release channel immediately.
- Claude subscription sign-in can paste the callback URL: the dialog keeps focus on the paste field and shows the URL in clear text.
- Providers UI: display names **Claude** / **ChatGPT**, an Add-provider type dropdown starting with OpenAI-compatible, and spacing between subscription and API-key lists.
- Detached `cypher headless` ignores SIGHUP when it has no TTY, so Settings no longer goes `connection closed` after the launching shell exits.
- iOS: tapping a session notification no longer crashes NavigationStack. Internal TestFlight **0.2.0 (9)** already carries that fix.
