# Cypher 0.3.16 — Model catalog follows background Runtime updates

- Engine: every Pi Runtime activation, including the six-hourly background update, now reloads model/command discovery and recycles parked Pi sessions, exactly like Settings → Install. A long-running host (typically a Linux headless service) no longer keeps serving the previous bundle's catalog — pi-claude-bridge's Claude models appear without an engine restart.
- Model picker: opening the menu revalidates already-loaded catalogs behind the visible rows. A failed refresh keeps the usable rows; the keyboard highlight only re-anchors when the rows actually changed.
- Ships Pi Runtime **0.85.1.5** (unchanged).
