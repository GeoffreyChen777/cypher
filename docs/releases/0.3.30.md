# Cypher 0.3.30 — Steer labels, a real pin, and kept optional comments

## Sessions

- **Steer messages are labelled, like on iOS.** A message sent into a running
  turn shows a muted "↳ Steer" caption over a fainter, outlined bubble, so it
  reads as a nudge to the live turn rather than a new prompt. The label comes
  from the session's command ledger, so it holds after a reload and for steers
  sent from another device; your own steer is labelled the moment you send it.
- **Skipping an optional comment no longer cancels the pick.** When an agent
  question offers an "Optional comment" step, leaving it blank or pressing Skip
  now submits the chosen option instead of telling the agent you cancelled.

## Sidebar

- **The pin icon is a pin.** Pinned projects and sessions, and the Pin menu
  items, use the pushpin glyph from the app's icon set instead of the old
  hand-drawn shape.
- Project cards carry a hairline ring so they separate from the frosted
  sidebar.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.2; iOS
ships separately as 0.2.0 (18).
