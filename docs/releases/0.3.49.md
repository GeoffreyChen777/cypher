# Cypher 0.3.49 — Commands that leave the sandbox, and clearer permission records

## Permissions

These apply with permission control turned on (Settings → Permissions).

- **A command that needs more than the sandbox runs outside it, once you
  allow it.** SSH, `git push` with your keychain's credentials, `gh`, cloud
  CLIs, `launchctl` and other processes used to need several approvals per
  command, or failed outright below Full access. Now the agent asks once:
  *Run this command outside the sandbox?*, with what it is for, the command
  and a pattern for similar ones. Choose Run once, Allow for this chat or
  Always allow; matching commands then run as you without asking.
- **Command rules.** Settings → Permissions lists the commands you allowed,
  with Remove; a rule can also make a command always ask or never run.
  Shells and interpreters can never be allowed this way, every command in a
  line must match, and a script the agent could edit is approved only at the
  contents you saw.
- **Simpler sandbox.** A sandboxed command never gets a secret, so it keeps
  the network. Your `~/.ssh/config`, known hosts and public keys are readable
  (private keys still are not). Approving a file for the agent's file tools
  says plainly that commands don't get it. The old one-command approvals and
  Linux's paused-command approvals are gone.
- **Switching a chat to Full access takes effect at once.** The agent's
  process used to keep running at the old level until it ended.

## Chats

- **Permission prompts are no longer questions.** In the transcript an
  approval sits on the command it gated, as a badge with a shield icon:
  *Outside the sandbox · this chat*, *Blocked by the sandbox*, *Denied*,
  *Allowed for this chat*. A command the sandbox blocked and its approved
  rerun read as one row, blocked and denied commands read calm rather than
  failed, and the work summary counts them ("Ran 3 commands · 2 outside the
  sandbox · 1 denied").

## iOS (Cypher Remote 0.2.0 (29))

- The same transcript rows and badges, a permission card in place of the
  question panel, `/permissions` in the `/` menu with the amber shield at
  Full access, and Permissions in the account menu for any of your devices.

Cut at build 1 on both desktop platforms. Pi Runtime 1.1.0.4 publishes after
the desktop release and requires Cypher 0.3.49 (an older app would show the
prompts' machine-readable line); iOS ships 0.2.0 (29).
