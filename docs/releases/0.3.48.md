# Cypher 0.3.48 — Permission control is now opt-in

## Permissions

- **Permission control is off unless you turn it on.** Settings →
  Permissions has a switch at the top, off by default. While it is off,
  agents use Pi's own tools as they did before 0.3.47: no sandboxed
  commands, no approval requests, and no scan of your home folder for
  sensitive files. Turn it on to get everything 0.3.47 introduced; the
  rest of the page (approval modes, the reviewing model, tools, files and
  network, always-allow rules) appears once it is on. A change applies
  from the chat's next turn.
- The switch is per device and only your own settings can turn it on; a
  project's `.pi/permissions.json` cannot.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 1.1.0.3,
which carries the switch; apps on 0.3.47 run it with permission control
off. iOS stays at 0.2.0 (28).
