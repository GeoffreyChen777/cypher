# Cypher 0.3.25 — A scrolling @ popup and quieter relay probes

## Composer

- **The @ mention popup scrolls.** With @session listing sessions from every
  project and device, the popup could hold more rows than its 320 px cap, and
  the card clipped the overflow: rows past the fold could not be reached with
  the mouse, and the keyboard highlight moved out of sight. The list now scrolls
  inside the card and follows the arrow keys, including the wrap from the last
  row back to the first, and resets to the top when a new mention starts.
- Long session titles and file paths truncate inside the highlighted row
  instead of running past it.

## Networking

- **A device whose room has never had a host is no longer re-probed every 30
  seconds.** The Edge answers `/device/{id}/status` with 404 when no host has
  ever joined the room and 403 when it belongs to someone else. The engine
  treated both as inconclusive, like a network failure, so they never reached
  the offline backoff: three engines kept asking about the same unhosted peer
  every sweep, the largest line on the Durable Object bill. Both are now
  authoritative "not live" answers and back off to the usual 30-minute cap.
  Network errors, 5xx, 429 and 401 stay inconclusive, and a peer that starts
  hosting later is not delayed, since its first presence beat clears the
  backoff.

Cut at build 1 on both desktop platforms. Pi Runtime is unchanged at 0.87.1.1;
iOS is unchanged at 0.2.0 (15).
