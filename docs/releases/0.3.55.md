# Cypher 0.3.55 — Recovery in the agent's language, and permission fixes

## Context recovery

- **The briefing matches the agent's language under translation.** With
  message translation on, a restarted turn's "Work already done" briefing
  and its added context were written in the language you typed, while the
  agent works in its own. Both are now written from your message as the
  agent received it, so the agent reads them in its language. Without
  translation nothing changes.

## Permissions (with Pi Runtime 1.1.0.7)

- **A Claude model can be the reviewing model.** Through the Claude bridge
  every review failed at once and reached you as "did not answer". Reviews
  now run as a separate one-off request and answer in seconds. When a
  review does fail, the card's Review row says why: the provider's error,
  or that it timed out.
- **Filters no longer make a command run-once-only.** A line like
  `ssh web 'sinfo' | awk '{print $2}' | sort | uniq -c` could only be
  approved for one run, because `awk` can run any command. Simple filters
  (`cat`, `head`, `tail`, `wc`, `sort`, `uniq`, `cut`, `tr`, `grep`, and
  `awk` or `sed` with a program that only prints) now ride along with the
  command that needs approval, so the line can be allowed for the chat.
  Options that write files or run commands (`sort -o`, `sed -i`, `awk`'s
  `system`, and the like) still don't count as filters.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 1.1.0.7,
published after the desktop release (it still requires 0.3.54). iOS stays
at 0.2.0 (31).
