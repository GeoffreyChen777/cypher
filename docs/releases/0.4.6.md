# Cypher 0.4.6 — a calmer workspace, and fewer permission prompts

## Workspaces

- **The chat only announces.** A proposed plan is a compact card with
  Details, Reject and Approve. When a plan or a routine's run ends, a short
  result card appears and the workspace's agent replies in a sentence or two.
  Nothing in the chat changes while work runs.
- **The left panel shows where things stand.** Each item gets one row: its
  state as a mark on the left and one quiet note on the right. Lists show a
  few rows and expand in place.
  - **Work:** a progress ring and the current step.
  - **Routines:** one line each, with a ring while a run is under way and a
    red mark when the last run failed.
  - **Projects:** the sessions the workspace runs there. These sessions no
    longer crowd the Sessions view, and they return to it when you delete the
    workspace.
  - **Connections:** a row for each connected workspace.
- **The right panel shows one thing in full.**
  - **Needs you** is one page for everything that waits on you (plans,
    permission prompts, questions, answers to review), and you answer each
    one in place.
  - Work, routine and connection pages put the status and every control at
    the top.
  - A workspace session opens live in the panel.
  - A button in the chat header opens and closes the panel.
- **iOS** uses the same marks and page layout. Decisions stay in the bar at
  the foot.
- A side chat opened in a workspace's chat can be closed.

## Permissions

- **Far fewer dialogs.** The reviewing model now approves, approves once or
  asks you. It no longer gives a confidence score. Building, testing, private
  dev instances, screenshots and read-only checks of the work you asked for
  run without a dialog. Replayed against last week's real prompts, 128 of 174
  would have run without asking, up from 77.
- **Dangerous steps you asked for in so many words.** A push, PR merge, tag
  or release runs without a dialog only when Cypher itself finds your words
  in the chat and checks that they name what the command does. The model
  saying so isn't enough. Words written by plans, routines, subagents and
  other workspaces never count. Removing only what the chat itself created,
  such as its own worktrees, branches or dev instance, is ordinary work.
- **Some things always ask.** You decide every time a secret would leave
  the machine, the permission system's own files would change, or no
  reviewing model is available.
- Sensitive files the model approves are read or written once and never
  remembered.

## Desktop

- **The Dock badge counts only chats you can see.** Hidden workspace
  threads no longer leave a number with nothing to clear.
- **Unread workspace results show.** A workspace with a finished, unread
  turn gets the green ✓ in the switcher, and the sidebar logo's dot says
  where. The current workspace is marked by its background, not a check.
- **Dismiss a failed send.** The "Send failed" row has an × next to Retry.
  The dismissal syncs to all your devices and lasts across restarts. A
  retry that goes through no longer leaves the old failure showing.
- **The side panel closes with its last tab.** Previously, closing it left
  the empty picker open.
- **The side panel's buttons stay put on hover.** The toggle and the open
  surface's buttons no longer jump just as the pointer reaches them.
- The workspace access line above the composer is gone.

## iOS

- **Long sessions no longer freeze the app.** The transcript measured every
  block of text three times on every layout pass. Long sessions could hang
  the app for 10 seconds, and iOS killed it on the way to the background.
  Each block is now measured once per width.

Cut at build 1 on macOS and Linux, with iOS 0.4.0 (47) for TestFlight.
Pi Runtime 1.5.2.3 carries the new permission review and needs Cypher 0.4.6,
which gives it your words to check.
