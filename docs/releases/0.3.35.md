# Cypher 0.3.35 — Copy that works, steadier Markdown previews, and a rail that stays out of the way

## Selecting and copying

- **Cmd+C copies selected chat text.** Dragging across the transcript or a
  diff highlighted text, but Cmd+C and Edit → Copy copied nothing. Both now
  copy the selection (Ctrl+C on Linux). The composer, Files editor and
  terminal still copy their own selections first.
- **Question cards can be selected and copied.** An agent's question, its
  context and its options are now selectable: drag, double-click and
  triple-click work, and Cmd+C copies even while the card has focus. Dragging
  or double-clicking an option selects its text; a plain click still picks it.
- **Selecting in a Markdown preview no longer jumps or freezes.** Dragging a
  selection in the Files panel's Markdown preview could jump around and, over
  time, freeze the app. Selection there is now steady; the Appearance chat
  preview gets the same fix.

## Workspace

- **The session rail floats over the tile.** The top-right button column now
  fades in over the tile instead of taking up width, so it no longer shifts
  the chat and dock.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.3; iOS
stays at 0.2.0 (19).
