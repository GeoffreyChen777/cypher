# Cypher 0.3.64 — Artifacts, Mermaid diagrams, and file chips

## Chats

- **Artifacts.** The agent can now write a page (an interactive demo, a
  chart, a simulation) as an artifact: a fence tagged ` ```html artifact
  title="…" ` (or `svg artifact`) shows in the chat as a card instead of
  its code. The card opens the page in a new Artifact tab in the side
  panel, with Preview / Source, Copy and Open in browser.
  - While the fence is still being written, the card reads "Writing…".
  - When the agent writes a page again under the same title, its open tab
    reloads.
  - Pages load with no access to your files or the project.
  - Plain ` ```html ` and ` ```svg ` blocks keep their code and gain a
    Preview button beside Copy. Side chats open theirs in the same panel.
- **Mermaid diagrams draw.** A ` ```mermaid ` block in a reply, or in a
  Markdown file's preview, draws as a diagram once it is complete; while
  it streams it shows as code. The block's header switches between the
  diagram and its source, Copy copies the source, and source that can't be
  drawn stays as code with the reason in the header. Diagrams take the
  chat theme's colors, shrink to fit the column (down to 60%) and scroll
  sideways past that.
- **File references are chips.** A path the agent cites as inline code,
  like `crates/ui/src/files.rs:69-73`, shows as a short chip: a file
  glyph, the file name and its lines. Hover it for a card with the cited
  lines as the file is now; click it to open the file in the Files tab with
  those lines selected. A bare or partial path is found in the checkout;
  when several files match, the card lists them instead of guessing.
  File links with a range (`a.rs:12-20`) now select the whole range.
- **The agent is told what the chat can show.** Every model now learns
  that replies render Markdown, math, Mermaid and artifacts, and is asked
  to name files the way the chips read them: relative to the working
  directory, the whole path every time, lines as `:42-58`. Your own
  `APPEND_SYSTEM.md` is left alone and still comes last. The file naming
  instructions ship in Pi Runtime 1.1.0.13, which devices pick up on
  their own.
- **Code blocks on the light theme** no longer sink into the grey chat:
  the block is lighter, its label sits as a caption over the code, and
  code blocks and artifact cards share rounder corners. A block's label
  is the language alone, so ` ```rust title=main.rs ` keeps its colors.
  Dark is unchanged.

## iOS 0.2.0 (37)

- **Artifacts open on the iPhone.** The same card shows in the chat; a tap
  opens the page full screen, with a menu to switch to its source or copy
  it. Web links in a page open in Safari. Plain HTML and SVG blocks get a
  Preview button.
- **Mermaid diagrams draw**, as on the desktop, fully offline.
- **Code block labels** show the language alone, keeping their colors.

Cut at build 1 on both desktop platforms, with Pi Runtime 1.1.0.13
(minimum Cypher stays 0.3.59). iOS moves to 0.2.0 (37); 0.2.0 (36), which
fixed the progress bar painting blank on its first frame, shipped on its
own.
