# Cypher 0.3.42 — The model's thinking, prompt navigation, and clearer messages

## Chats

- **The model's thinking is shown, folded.** While a model thinks, a
  "Thinking…" line appears above its reply; once it's done it reads
  "Thought". Both stay collapsed until you click them. Thinking syncs to
  your other devices, which see it with the reply's next update rather
  than live. Older versions skip it, so a mix of versions is safe.
- **↑ and ↓ jump between your messages.** Click into the chat history,
  then ↑ goes to the previous message you sent and ↓ to the next; past the
  last one, ↓ returns to the bottom. The composer's own arrow keys are
  unchanged.
- **Your messages stand out.** Your message bubbles are now a muted blue
  in light and dark mode instead of a grey close to the page, and stay
  distinguishable without relying on color alone. A custom bubble color or
  color preset still takes precedence.
- **Reduce Motion keeps your place.** With Reduce Motion on, jumping to a
  message from the message rail no longer snaps back to the bottom.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.0.1.3; iOS
moves to 0.2.0 (24) with the same bubble color and thinking display, and
folds a translated reply's original by default.
