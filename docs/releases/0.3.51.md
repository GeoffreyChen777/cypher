# Cypher 0.3.51 — See what each round changed, and diffs that read like diffs

## Chats

- **Each round lists the files it changed.** When the agent finishes a
  round (from your prompt to the moment it stops), its last answer now
  shows the files that round changed, with a summary such as "6 files
  changed +46 −4". Clicking a file opens the round's diff at that file in
  its own tab in the right dock; Review opens the whole round. A message
  sent while the agent is working extends the round, and a round that
  changed nothing shows nothing. The list syncs with the chat to your other
  devices. The diffs come from snapshots Git eventually cleans up, so a
  very old round's diff may no longer open; the tab says so.
- **Diffs in replies render as diffs.** A ```` ```diff ````, `patch` or
  `udiff` block in a reply now looks like the Changes pane: coloured
  added and removed lines, hunk headers, and a file header with +N −M
  counts, with syntax colours when the file's language is known. Copying
  still copies the raw block.
- **Scrolling past wide blocks stays vertical.** Scrolling down over a code
  block, diff or table could slide it sideways instead. Wide blocks now
  only scroll sideways for a mostly sideways gesture; everything else
  scrolls the chat.

## Sidebar

- **The focused project's card glides.** Selecting a session in another
  project now slides the highlighted card over to it instead of
  crossfading.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.1.0.4 and
iOS at 0.2.0 (29).
