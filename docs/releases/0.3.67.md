# Cypher 0.3.67 — Paired devices, a hardened engine, and an explainer that patches its page

## Security

- **Pair your devices.** Until now, signing in to your account was all it
  took to drive any of your devices remotely, so a stolen sign-in or a
  tampered server could reach every machine's terminals and files. Your
  devices can now form a trust group whose keys never leave them, and
  calls between paired devices run end to end encrypted, so the server
  can neither read nor forge them.
  - Settings → Devices → Pairing: Add a device shows a one-time code;
    enter it on the new device, then approve it here. You can unpair a
    device from the same place, and removing a machine from Devices now
    unpairs it too. Each device's row shows Paired or Not paired.
  - **Only paired devices** is a group switch: when on, every device in
    the group refuses calls from devices outside it. It is off by
    default. An iPhone on an app older than 0.2.0 (39) can't pair, so
    turning it on cuts that phone off until it is updated and paired.
  - A removed device's keys are banned for good; the same machine can
    pair again with fresh keys.
- **Agents get a restricted connection to Cypher.** The agent could call
  anything the app can on its local engine connection, including
  terminals and other devices. It now gets a connection of its own that
  only starts subagents and runs its own subagent chats. The app's own
  connection needs a key that is created fresh for each engine start.
- **Credentials move into the login Keychain** on macOS: your Cypher
  sign-in, the GitHub account and the engine connection's key. Other
  programs, an agent's shell included, now need your approval to read
  them. Existing files move over on first use, so you stay signed in.
  Linux keeps them in private files.
- **Only curated Pi packages** can be installed or enabled; enabling an
  arbitrary path or npm name used to load it as an extension.
- **Sign-in tokens no longer travel in URLs** of sync connections, and the
  server no longer logs request URLs and headers.

## Artifacts

- **`/explain` patches its page.** With `/explain` on, every reply that
  changed the work rewrote the whole "Session explainer" page, which was
  slow and costly for a one-line change. The agent can now send just the
  edits for a small change and the whole page only for a large one.
  The open tab reloads with the edits, and the reply's card reads
  "Updated · N edits", warning when an edit didn't apply or there was no
  page to edit.

## iOS 0.2.0 (39)

- **Join your paired devices.** Account › Paired devices joins the group
  with a code shown on a paired desktop. Calls to paired desktops are
  then end to end encrypted, and a link opened before pairing upgrades
  itself. With Only paired devices on, the phone refuses unpaired hosts.
- **Artifact edits apply**, as on the desktop: an explainer's edits update
  its page, and every card opens a page's newest version, even when the
  page was written long before the messages on screen.
- Sign-in tokens no longer travel in sync connection URLs.

Cut at build 1 on both desktop platforms, with Pi Runtime 1.1.0.15, which
keeps agents out of the GitHub account file (minimum Cypher stays 0.3.59).
iOS moves to 0.2.0 (39).
