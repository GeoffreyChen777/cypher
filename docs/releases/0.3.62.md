# Cypher 0.3.62 — HTML previews, a quieter session rail, and per-run subagent models

## Files

- **HTML files preview.** An `.html`, `.htm` or `.xhtml` file opens in
  Preview, like Markdown and SVG, with the Source / Preview toggle in the
  header. The page fills the pane under the header and stops short of the
  dock's floating rail.
  - A saved file on this Mac loads from disk, so its relative
    stylesheets, scripts and images load too. Unsaved edits and files on
    another device show the page from its text.
  - Web links open in the browser; anchors and relative pages stay in the
    preview. Clicking back into Cypher takes the keyboard back from the
    page.
  - The page hides while the Files menu, a delete confirmation or any
    dialog is open, so nothing is covered.
  - macOS only; on Linux HTML still opens as source.

## Sessions

- **The session rail collapses until you hover it.** The rail in a
  tile's top-right corner showed every button at all times and covered
  the top of the side panel. It now shows only the side-panel toggle and
  what is on: an open terminal, a zoomed tile, the side panel's shown
  surface. Hover it to slide the full rail open; it stays open while its
  + menu is open or a surface is being dragged, and folds away a quarter
  second after the pointer leaves. With Reduce Motion it switches at
  once.

## Chats

- **Scrolling no longer stops dead after you send in a remote session.**
  A remote reply arrives in batches, and a long one could outgrow the
  measured part of the transcript between two frames. The scroll hold
  set up when you sent then never let go, so scrolling down stopped at
  your prompt with most of the reply out of reach. The hold now releases
  as soon as the reply fills the space reserved for it, without moving
  anything on screen.

## Progress bar

- **Long chained commands move the bar.** A command that chains several
  steps reached the progress reader as one line cut at 160 characters, so
  the later steps were often lost, and while it ran nothing changed, so
  no new reading was asked for. The latest and any running commands now
  keep up to 600 characters with their lines, and a running tool's last
  three lines of output count as new activity.
- **The current dot follows the fill.** The current step's ring, its
  tooltip and hover target now move with the fill as it animates to a new
  reading, instead of jumping to where the step began. Passed steps still
  never move.
- **The current ring breathes smoothly.** It grew in a few visible steps
  each breath and briefly went oval. It now scales evenly at every size,
  at no measurable extra cost.

## Subagents

- **The orchestrator can choose a subagent run's model and thinking
  level.** The `subagent` tool takes optional `model` (`provider/model`,
  or a bare id only one provider offers) and `thinking` for that one run,
  without rewriting the agent's file. An unknown or ambiguous model, or an
  unknown level, is refused with the choices before anything starts. A
  thinking level alone keeps the agent's model. This ships in Pi Runtime
  1.1.0.12, which devices pick up on their own.

Cut at build 1 on both desktop platforms, with Pi Runtime 1.1.0.12
(minimum Cypher stays 0.3.59). iOS stays at 0.2.0 (34).
