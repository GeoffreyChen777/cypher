# Cypher 0.3.32 — Pull requests in the composer, a steadier Files editor, and disk space back

## Composer

- **Type # to reference a pull request, too.** The # popup now lists issues
  and pull requests in separate sections, each with its own icon and up to 10
  rows. Assigned rows still lead each section, an exact number puts that issue
  or pull request first, and merged or draft pull requests say so. A picked
  pull request becomes its own chip, and the agent prompt names it as a pull
  request.

## Files

- **The editor no longer crashes mid-edit.** Deleting within a line, or typing
  CJK, before the syntax highlighter caught up could crash the Files editor.
  Highlighting now always fits the line being edited; the Changes view shares
  the fix.

## Storage

- **Old Pi Runtimes and app updates are cleaned up automatically.** Every
  Runtime release and every macOS update used to leave its previous copy
  behind — a long-lived install could hold ~9.5 GB of them. The engine now
  keeps only the Runtime in use (sparing any a running agent still loads from),
  and the updater drops staged macOS bundles and Linux app versions at or below
  the running one. Linux never removes a version a live process or service unit
  still uses.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.3; iOS
stays at 0.2.0 (19).
