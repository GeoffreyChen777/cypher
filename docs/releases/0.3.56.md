# Cypher 0.3.56 — Edit the appended system prompt, and no more stray Claude Code sessions

## Agents

- **Edit the system prompt every Pi chat appends.** Every Pi chat adds the
  agent directory's `APPEND_SYSTEM.md` to its system prompt (for Claude, to
  Claude Code's own prompt), but nothing in Cypher could edit it. Settings →
  Agents now has a card for it, per device. Saving applies from each chat's
  next message; clearing the text removes the file. Files over 64 KB are
  refused.
- **Claude Code sessions created by the bridge are cleaned up** (with Pi
  Runtime 1.1.0.8). Every Pi restart — idle shutdown, Restart from here,
  context recovery, an engine restart — left a copy of the conversation in
  `~/.claude/projects`, next to your own Claude Code sessions, forever. The
  bridge now records the sessions it creates and deletes them when its
  process exits; if a process was killed, the next one sweeps its leftovers.
  Only sessions the bridge recorded are ever deleted — your own Claude Code
  sessions are never touched. Files already left by earlier versions stay.

## Model picker

- **A quieter provider rail.** The divider and selection plate are gone:
  the rail is one raised card, and the selected provider shows in its
  brand colour while the rest stay grey. Unbranded providers get a
  one-letter tag on their globe.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 1.1.0.8,
published after the desktop release (it still requires 0.3.54). iOS stays
at 0.2.0 (31).
