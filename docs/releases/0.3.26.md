# Cypher 0.3.26 — Translated quotes, safer forks, and fewer billable requests

## Translation

- **A quote taken from a translated answer reaches the agent in its own
  words.** With Pi translation on, a comment or Side Chat quote selected from a
  translated answer (or from a prompt shown as typed) used to send the agent
  text it never wrote, and the extension then translated the whole wrapped
  prompt again. The transcript now keeps the agent's version of translated
  text, maps a selection back to the original passage it came from, and the
  extension resolves it to the exact words. When that fails the agent gets a
  back-translation labelled as approximate, or the passage alone. The displayed
  translation itself never reaches the agent, and every agent other than Pi
  gets the alignment input stripped by the engine.
- Wrapped prompts (comments, referenced sessions, a Side Chat's first send)
  share one layout, so only the request and the comment notes are translated.

## Sessions

- **Session Fork and Restart map translated, command and /goal sessions.**
  They used to refuse on any mismatch between Cypher's prompts and Pi's user
  entries. They now read the prompt's original text from the translation
  record, skip slash commands, fall back to position when counts agree, and
  refuse ambiguity only when the fork lands on the ambiguous prompt. A refusal
  now shows the helper's reason.

## Git panel

- **Files inside a brand-new directory show up.** Untracked files are listed
  individually instead of collapsing into one unreadable `dir/` record.

## Markdown

- The inline-code wash is sized from the font rather than the line height, so
  raising the Markdown line height no longer stretches every code pill.

## Networking and billing

- **WebSockets go through the same HTTP proxy as HTTP requests.** Dials honour
  `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` and `NO_PROXY` with reqwest's
  precedence and tunnel through an HTTP `CONNECT`. Loopback is never proxied,
  `https://` and SOCKS proxies are left alone, and a failed tunnel falls back to
  a direct dial. Behind a proxy-only network this restores live sync and
  presence instead of polling over HTTPS every 30 seconds.
- **A desktop viewport transition rides the open socket.** Switching chats or
  focusing the window no longer spends an HTTP request when a socket is live;
  HTTP stays the fallback when no socket is live.
- **A chat the Worker has declined is no longer re-reported every heartbeat.**
  An `ignored` notification report backs off from 30s to a 600s cap after its
  first quick retries. The Worker now also says which rule fired.
- **The unused chat tail is no longer uploaded.** Nothing had read
  `/chat2/{id}/tail` since iOS read chat2 natively. The Edge still accepts it.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 0.87.1.2 to ship
the translation extension changes; iOS is unchanged at 0.2.0 (15).
