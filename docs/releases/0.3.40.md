# Cypher 0.3.40 — Token speed that holds up, on every device

## Chats

- **Token speed reads right through bursty streams.** Claude through the
  bridge delivers each message after a tool result in one burst just before
  it ends, so the live tok/s never warmed up and a lone chunk after a pause
  read as 0–1 tok/s. Each finished message now reports its average speed,
  and the trailer shows that whenever there's no fresh live rate. A pause
  of more than a second restarts the warm-up.
- **Other devices see the token count and speed too.** The reading rides
  the session's existing status updates, so another Mac or Linux machine
  watching a running chat shows its tokens and the last message's speed, a
  few seconds behind the host. No extra sync traffic is added.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.0.1.2; iOS
ships separately as 0.2.0 (23).
