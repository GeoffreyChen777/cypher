# Cypher 0.3.31 — GitHub issues in the composer, a Dock badge, and badges that clear everywhere

## Composer

- **Type # to reference a GitHub issue.** In a project with a GitHub remote,
  # lists that repository's issues: yours first, then recently updated, and an
  exact number jumps straight to that issue. A picked issue becomes a chip; on
  send, the chat's host device snapshots it (body, labels, newest comments,
  bounded) into the prompt as untrusted reference context. A new worktree
  started from an issue is named after it.
- **Sign in to GitHub per device.** Settings → GitHub signs a device in with
  the Cypher GitHub App through the device flow; the token stays on that
  device and never syncs or crosses the relay. Without a sign-in, the device's
  `gh` login or git's saved github.com credential is used instead, and the #
  popup offers sign-in or the app install when a repository isn't visible.

## Notifications

- **The Dock icon counts sessions waiting on you** — finished, failed or
  asking — on macOS. Opening a session clears it; Settings → Notifications has
  a toggle.
- **Opening a session on any device clears its badge on every device.** The
  unread row and any delayed alert are dropped, and phones get a badge-only
  update.

## Agents

- **/orchestrate works on Claude.** The squad's orchestrator prompt (or its
  delegation guard) was silently dropped by the Claude bridge; it now reaches
  Claude Code. This ships in Pi Runtime 0.87.1.3, which devices pick up on
  their own.
