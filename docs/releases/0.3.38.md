# Cypher 0.3.38 — Pi 1.0, built-in MCP, Scripts, and a / menu you choose

## Pi 1.0

- **Pi Runtime 1.0.1.2 ships with this release.** Pi moves from 0.87 to
  1.0.1. Devices on 0.3.38 pick the Runtime up on their own; older versions
  of Cypher keep their current Runtime.
- **MCP runs on Pi's built-in support.** The separate MCP adapter is gone.
  Settings → MCP looks and works the same, and existing servers are
  converted automatically. **Each MCP server that uses OAuth needs to sign
  in once more**, since the adapter's stored sign-ins are removed.
- **Scripts.** When the model writes a script that calls several tools, the
  transcript shows one Script card named after the tools it uses, with its
  code and the calls it made nested underneath. MCP calls are named by their
  server, web searches show their query, and every call shows its status as
  an icon. Scripts is a per-chat switch: `/scripts` turns it on or off, and
  it's on by default.
- **/fast follows new GPT models.** Fast mode now applies to every GPT model
  from 5.4 on, including new releases, instead of a fixed list. Chats keep
  their current setting.
- **Messages sent while a turn runs land once.** A message sent mid-turn
  could reach the model twice, and a slash command sent mid-turn could be
  silently dropped. Both are fixed.
- **Compaction no longer fails on older sessions** with
  "message.content.filter is not a function".
- **Claude through the bridge** keeps its 1M context on Opus 5.5 and gains
  it on Sonnet 5.5, and turns no longer hang after a stalled stream.
- **Agents can ask up to four questions at once**, answered one after
  another in the usual question card.

## Composer

- **The / menu shows only the commands you turn on.** Choose them in
  Settings → Commands, now grouped by purpose; settings-only commands sit
  behind each group's Advanced row. `/` with nothing turned on opens no
  menu, and typed commands still run. `/scripts` is shown by default once.
- **The / menu is grouped and tells you the current state.** Commands sit
  under the same headings as Settings, each with its own icon. Fast mode,
  orchestration, Scripts and goals show On/Off or their status, /compact
  shows how full the context is, and commands with named choices (such as
  /orchestrate on|off|status) open a list with the current one checked.
- **Attach files moved into the / menu.** The paperclip is gone from the
  composer; "Attach files" is the first row of the / menu (also found by
  typing "files", "image" or "upload"). Paste and drop still attach.
- **The context gauge is an arc around the send button.** It replaces the
  ring in the chip row; hovering shows the reading and clicking compacts,
  as before. The composer also gets a soft shadow on every theme, glass
  included.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 1.0.1.2,
published after both desktop channels reach 0.3.38; iOS stays at 0.2.0 (20).
