# Cypher 0.3.22 — A Files surface in the right pane

## Files

- **The right pane has a third surface beside Terminal and Git.** A lazy
  directory tree over the selected chat's checkout, read on the device that
  hosts it, sits beside a tree-sitter-colored editor for the file you pick. The
  browser is the engine's existing `ListWorkspaceFiles`/`ReadWorkspaceFile` pair
  — built for iOS, now shared by the desktop — so a chat hosted on another
  device browses that device's checkout, not this one's.
- **Cmd+S saves.** A new `WriteWorkspaceFile` RPC rewrites an **existing**
  regular file through the same anchored, no-symlink open as the reads: it
  creates nothing, follows nothing out of the checkout, and stays bounded. A
  read that came back truncated or binary opens read-only, so a partial read can
  never be written back over the whole file.
- **Markdown opens rendered.** Markdown files use the transcript's own renderer,
  with fenced code highlighted in the background and a Source / Preview toggle in
  the surface header. A wide pane splits tree and editor; a narrow one shows one
  at a time.

## Under it

- The editor shapes only the lines you can see — unwrapped, virtualized per line
  — and re-highlights 120ms after you stop typing, so a large file stays
  responsive while being edited rather than only while being scrolled. It
  carries a line-number gutter, selection, IME composition, coalescing undo/redo,
  word and page moves, auto-indent, and display-only tab expansion. Highlight
  rows tolerate the syntax crate omitting the empty row after a trailing newline.

## Pi turns

- **A Pi turn no longer ends at the prompt ACK.** Every turn of a chat "ended
  early": the harness emitted `Done{Completed}` the instant pi acknowledged the
  prompt, before the agent's first event. The engine parked the session, then
  re-admitted the whole turn as self-continued output under the 20s watchdog, so
  each later pause over 20s parked it again.
- The cause was status furniture counting as interaction. Any
  `extension_ui_request` set `had_ui`, and `had_ui && !agent_started` collapsed
  the no-activity grace to zero when the ACK arrived — but the goal, MCP and
  subagents extensions push `setStatus` at startup and mid-turn, and the
  translation extension delays the ACK by seconds. Only blocking dialogs and
  notify set `had_ui` now, and the zero-grace shortcut also requires a slash
  command, so a plain prompt always keeps the full grace. A new fixture scenario
  (`status-before-ack`) replays the real sequence and fails on the old code.

Cut at build 1 on both desktop platforms. The Pi Runtime stays on 0.86.0.2 and
iOS on 0.2.0 (14); nothing in this release touches either.
