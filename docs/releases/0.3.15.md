# Cypher 0.3.15 — Claude Code, model catalog, and Agents polish

- Claude in Settings → Providers is now the Claude Code CLI via **pi-claude-bridge** (pinned from GitHub), not Pi’s built-in Anthropic OAuth. Missing `claude` prompts to install; ChatGPT subscription sign-in is unchanged.
- Model picker waits until configured providers (including custom NewAPI gateways) appear, so Claude Bridge no longer hides the rest of the catalog.
- Question panel: pinned chrome with close, divided prompt/context/options, and Context shown as smaller faint body text without a heading.
- Model picker rail is grouped by provider.
- Agents: Runtime version card, compact Automatic titles dropdown, and the plugin list is no longer shown (Runtime ships the curated set).
- Right panel can be dragged up to 1.8× the previous max (1368px / 94% of the window).
- Ships Pi Runtime **0.85.1.5**.
