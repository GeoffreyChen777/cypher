# Cypher 0.3.57 — Subagent questions reach the main chat

## Subagents

- **Questions and permission requests from subagents show in the main
  chat.** A subagent runs in a hidden child chat, so a question or a
  permission prompt it asked waited there where you could not see it. A
  copy now appears in the main chat, even after the main chat's turn has
  ended, and your answer goes back to the subagent. The card reads
  "Question from <agent>" or "Permission request from <agent>", and the
  main chat shows as awaiting input until you answer. If the question is
  settled in the child chat first, the copy closes on its own.

## Turn changes

- **Chats starting a turn at the same moment no longer mix up their
  changes.** Two chats that started a turn in the same microsecond shared
  one temporary git index. One chat's snapshot could then be lost, or a
  round could record its whole checkout as added. Each snapshot now gets
  its own index.

## macOS

- **Built against the macOS 26 SDK.** Release builds linked against the
  macOS 15 SDK, so on macOS 26 the app ran in compatibility mode and could
  look and behave unlike local builds. The minimum macOS version is
  unchanged.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.1.0.8; iOS
stays at 0.2.0 (31).
