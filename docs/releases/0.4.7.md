# Cypher 0.4.7 — fewer wrong permission questions, and a queue that keeps moving

## Permissions

- **A secret leaving the machine is asked about only when one can.** A
  workspace's chats run in its own folder inside Cypher's data, and every
  word of an `ssh`, `curl` or `gh` line run there was taken for a secret
  file. So every remote command from a workspace asked "it sends a secret
  off this machine". Now only what the line can actually read counts: a
  sensitive file that exists or is named in full, the keychain, the
  environment, or a credential variable the line expands. A URL, an ssh host
  or the command it runs, an option's value, or a key used only to connect
  doesn't count.
- **A workspace's folder is its project** for its own chats, both in the
  review and in the sandbox. Commands there no longer fail on `pwd`. Secrets
  in it, other workspaces' folders and transcripts stay closed.
- **Attachments are read without a question.**
- **Your latest words count.** A running agent checks a dangerous step
  against everything you have written in the chat so far, not only what was
  there when the run started.
- **The shell reader understands more lines**: `case`, `{ …; }`, `$((…))`,
  a heredoc inside `$(…)` (as in `git commit -m "$(cat <<'EOF' …)"`), and
  `find -exec` judged by the command it runs. A later "don't" takes back a
  request only when it is about that request.
- **Where it asked too little:** a project's `.pi/permissions.json` can no
  longer be changed by the agent's file tools or sandboxed commands. A grant
  for a folder no longer covers the permission system's files inside it.
  "Open a PR, don't merge it" no longer covers a merge. `scp ~/.ssh/id_* host:`
  is caught.

## Workspaces

- **Plans run as long as you say.** A workspace's settings now hold a plan's
  time limit (4 hours unless you change it, up to 72), how many plans run at
  once and how many sessions one plan may start. Ask for more time in the
  request ("give it 8 hours") and the plan card says so. A running plan's
  page has **+1h**, and 15 minutes before the limit the plan is told to wrap
  up and report, so you get a result instead of a stopped plan.
- **Choose the model, thinking level and Fast mode** of the sessions a
  workspace starts: a default in its settings, per routine in the routine
  form, and per plan step or session when you ask for it ("use Opus with
  high thinking for the fix"). The plan page shows what each step runs on.
- **Smaller tool options:** a session can start in a new worktree in one
  step, a worktree's branch can be named, and "run the morning brief, but
  only for cypher" runs a routine once with that note, leaving the routine
  as it was.
- **Shift+↑ / Shift+↓ switch workspaces**, going through Sessions and then
  each workspace in sidebar order. Rebind them in Settings. In a text field
  Shift+arrows still select text, except in an empty composer.
- **Needs you closes when you are done.** Deciding the last item on the page
  slides the panel shut once the decision is confirmed. A failed decision or
  a new item keeps it open.
- **Shortcuts:** the field a shortcut asks for its text in has the chips'
  size. The text is optional: Enter on an empty field sends the request.
  Double-clicking a chip sends it at once.

## Chats

- **An unfinished image upload no longer blocks a chat.** A message whose
  image never finished uploading held every later message in the queue,
  even after a restart. The upload now outlives the composer that started it.
  A failed upload is reported to the chat right away and the draft comes
  back, and a waiting message gives up on time even when nothing else happens
  in the chat.
- **Bold closes next to Chinese and Japanese punctuation.** `**…。**旧版`
  used to show the asterisks. It now renders bold.

## iOS

- **Plans and sessions in workspace settings.** The settings sheet has the
  plan time limit, plans at once, sessions per plan, and the model, thinking
  level and Fast mode of the sessions a workspace starts. The routine form
  chooses thinking and Fast mode beside the model, and a running plan's page
  has **+1 hour** with the time left.
- **The app badge counts what the Dock badge counts.** Hidden workspace
  threads, memory passes and the finished runs of sessions a workspace
  started no longer reach the phone. Questions from a workspace's sessions
  still do. This shipped as a server update.

Cut at build 1 on macOS and Linux, with iOS 0.4.0 (48) for TestFlight. Pi
Runtime 1.5.2.4 brings the permission changes and Fast mode for sessions a
workspace starts, and needs Cypher 0.4.7, which answers its questions about
your latest words and the workspace's folder.
