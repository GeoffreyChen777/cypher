# Cypher 0.3.39 — Sent messages no longer show as interrupted, and a fuller / menu

## Chats

- **A message that ran no longer shows "interrupted before completion".**
  When two checks of a chat's queue overlapped, one could act on an outdated
  copy and mark a message that had already run as interrupted, inviting a
  retry that would send it again. A message is now only marked interrupted
  if it is still waiting when checked, which is what happens when Cypher
  quits mid-send.

## Composer

- **The / menu shows its stateful commands by default.** /compact, /goal,
  /fast, /scripts, /orchestrate and /subagent-status, the commands whose row
  shows what is in effect, now appear without a trip to Settings →
  Commands. Existing installs pick them up once on their next launch; one
  you turn off stays off. Everything else still waits to be turned on.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 1.0.1.2; iOS
stays at 0.2.0 (20).
