# Cypher 0.3.27 — Model switches that take effect, a context gauge, and a clearer sidebar

## Sessions

- **Switching the model in an existing chat takes effect on the next send.**
  Pi keeps its process parked between turns, and the next message used to go
  straight into it, so the reply still came from the model the process was
  launched with while the chip showed the new one. The switch only took hold
  after the 30-minute idle reaper, a stop, or an engine restart; reasoning
  level and model options had the same problem. A parked run whose settings
  differ is now ended cleanly and the turn starts a fresh process on the same
  Pi session file, so the conversation carries over. A turn already running
  finishes on its current model.

## Composer

- **Context usage shows as a ring beside the model chip.** It is muted, turns
  amber from 75% and red from 90%, and its tooltip reads e.g. "62% context
  used · 124k / 200k". Clicking it sends `/compact` as an ordinary run without
  touching the draft, attachments or comments. It is disabled mid-turn and for
  agents without `/compact`. Claude and Codex report usage over ACP; Pi is read
  after each assistant message, on settle and after a compaction.
- A `/compact` sent to a parked Pi session now runs the compact command instead
  of reaching the model as prompt text.

## Sidebar

- **Project, checkout and session read as three distinct levels.** Project
  titles are the strongest type, checkout sections are small muted captions on
  shorter rows, and sessions sit below both. Where a project has several
  checkouts, a thin rail runs from each section down its sessions in place of
  the divider lines; the disclosure chevron appears on hover, and a collapsed
  section counts its hidden sessions.
- A project with a single ordinary checkout lists its sessions directly, with
  the branch shown after the project name, instead of repeating a "main" or
  "Current checkout" header.
- Host names appear only when the sidebar spans several devices, and then on
  hover, or always while the host is offline. A project with no sessions dims
  its title; a collapsed one shows its session count.
- Quick chats from every device share one card, sectioned by device when there
  are several.
- The agent mark before each session appears only when the sidebar mixes
  agents; with Pi alone every row showed the same glyph, so titles now line up
  with the project name.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.2; iOS is
unchanged at 0.2.0 (15).
