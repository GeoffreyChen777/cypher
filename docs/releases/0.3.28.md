# Cypher 0.3.28 — Pi runs no longer hang on a late context reading

## Sessions

- **A Pi run's event stream closes even when a context reading is still in
  flight.** 0.3.27 started reading Pi's context usage in the background after
  each assistant message, on settle and after a compaction. A reading that
  raced Pi's exit, or outlived its session, waited forever for an answer that
  could never arrive, and kept the run's event stream open with it. Any
  request the Pi client can no longer answer now fails at once.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.2; iOS is
unchanged at 0.2.0 (15).
