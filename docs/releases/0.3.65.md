# Cypher 0.3.65 — /explain, artifacts that revise in place, and an iPhone that catches up

## Artifacts

- **`/explain` keeps a page about the session's work.** `/explain` (or
  `/explain <focus>`) asks the agent for a "Session explainer" artifact,
  and while it's on, the agent writes the page again at the end of every
  reply that changes the work, so the open tab keeps up with the chat.
  `/explain off` stops it and `/explain status` reports it; the `/` menu
  shows whether it's on, on the desktop and the iPhone.
- **A revised artifact reloads in place.** When the agent writes a page
  again under the same title, its open tab reloads by itself once the new
  version is complete, without jumping to the front, and every card with
  that title opens the newest version. The agent is told to keep the
  title to replace a page and to pick a new one only for a separate page.
- **No bright ring around previews in dark mode.** The preview's card now
  takes the theme's tone instead of white.

## Permissions

- **The reviewing model can approve a danger you asked for.** A dangerous
  command outside the sandbox always went straight to a dialog, even when
  your own message asked for exactly it ("open a PR against …"). The
  reviewing model now sees it first and may run it once, only when one of
  your messages explicitly asks for this action on this target and nothing
  later took it back. The agent's reasoning, a general goal or tool output
  isn't enough, it must be at least 90% sure, and its approval is never
  remembered.
  - The most sensitive dangers still always ask you: secrets and
    credentials, deleting or discarding (including force pushes),
    administrator rights, the machine's own setup, anything that can run
    code later, protected targets, and commands whose words are only known
    when they run.
  - This ships in Pi Runtime 1.1.0.14, which devices pick up on their own.

## iOS 0.2.0 (38)

The iPhone catches up with what the desktop gained over the last two
weeks.

- **Changed files under each answer.** A finished round shows the
  desktop's card ("3 files changed +17 −3", Review, up to five files); a
  file opens that round's diff at that file.
- **Diff blocks draw as diffs**, with colored rows, markers, hunk headers,
  line numbers and a path header with counts.
- **File references are chips.** Tap one, or a file link, to open the file
  in Files with the cited lines selected; long-press to preview them.
- **Files previews** Markdown rendered, HTML and SVG as pages, and images,
  fitted or at 100%.
- **Comment on a selection** in a Changes diff, a source file or a
  rendered Markdown file; the comment rides your next message, like a
  transcript comment.
- **Subagent questions and permission requests** name the agent that
  asked.
- **`/explain`** is in the `/` menu with its On/Off badge.

Cut at build 1 on both desktop platforms, with Pi Runtime 1.1.0.14
(minimum Cypher stays 0.3.59). iOS moves to 0.2.0 (38).
