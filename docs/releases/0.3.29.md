# Cypher 0.3.29 — Attach any file, a clearer question card, and folded translations

## Composer

- **Attach any file type, not just images.** The picker, drag and drop, and
  pasted Finder files now stage any file up to 24 MB; folders and unreadable or
  oversize files say so instead of silently vanishing. Non-image files show as
  a rounded bar with a document icon and name, in the composer and above the
  sent bubble, stacked under any image thumbnails.
- Pasted macOS screenshots (uncompressed TIFF) and BMP images are re-encoded to
  PNG when staged, so vision models accept them — a 6.3 MB screenshot became
  326 KB. Other image types the providers reject ride along as a path instead
  of failing the turn.
- Upload names keep Unicode letters: "季度 报告.pdf" no longer becomes
  "__.pdf".

## Sessions

- **A prompt's comments are recorded on its user entry and shown in the
  transcript**, laid out like the user bubble, with selectable text.
- **The agent question card leads with the question.** It reads top to bottom
  by importance: who is asking and the step ("2 of 3"), the question as the
  headline, its context as a quoted block, then the options with their number
  keys and descriptions. A multi-select that used to arrive as a numbered list
  to answer by typing is now real checkboxes, the "Type custom response"
  sentinel is a "Write a different answer…" row, and Enter with nothing picked
  waits instead of sending an empty answer the agent read as a dismissal.
- The context ring now shows a remote host's usage on every device, synced
  through the session's status row.

## Translation

- **Append is the default output mode, with the original folded away.** The
  transcript hides the original answer behind a "Show original" toggle, so a
  translated answer reads like replace mode with the original one click away.
  The rail's reply preview shows the translation too. A saved "replace" choice
  is kept.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.2; iOS is
unchanged at 0.2.0 (15).
