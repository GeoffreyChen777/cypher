# Cypher 0.4.3 — Linux updates that take

## Linux

- **Updates no longer loop.** A service set up before Cypher's
  `~/.cypher/app/current` layout starts one fixed version. Updating only
  switched `current` and restarted, so the service came back on the old
  release, found the update again and restarted, about every 24 seconds.
  Desktops kept showing the old version with an update available.
  - Every update path now points such a service at `current` before it
    restarts: auto-update, a desktop's **Update**, and `cypher update`,
    even when the binary is already current.
  - A device that starts behind its installed release repoints its
    service once and restarts onto it. If the service can't be repointed,
    the device stops retrying and its Devices row says to run
    `cypher daemon install` there.
- **A device already stuck needs one command.** Its running engine is the
  old version and can't repair itself. Open a terminal on the device from
  Cypher on your Mac, or over SSH, and run `cypher daemon install`. An open
  terminal pauses the restart loop while you do.

Cut at build 1 on Linux only; macOS stays at 0.4.2 (1), iOS at 0.4.0 (44)
and Pi Runtime at 1.5.2.1.
