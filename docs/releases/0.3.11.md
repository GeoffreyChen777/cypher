# Cypher 0.3.11 — sync cost and UI fixes

Published from the restored stable baseline with incremental, backwards-compatible
client optimizations:

- de-duplicate registry wakeups;
- back off repeated probes of explicitly offline devices;
- avoid release checks on ordinary token rotation;
- suppress notification heartbeat duplicates while preserving transitions and retries;
- use HTTP sync only for bootstrap/recovery while a healthy chat2 WebSocket is active;
- recover queued writes when ACKs or row repairs stall;
- reduce background activity reports and duplicate tail sidecar uploads;
- fix semantic plugin icon precedence and terminal appearance test regressions.

The chat2 wire protocol, storage format, formal application data, and Cloudflare
Durable Object schema are unchanged. This release has not deployed a Cloudflare
Worker change; the optimizations are client/engine-side.
