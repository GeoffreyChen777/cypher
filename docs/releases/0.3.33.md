# Cypher 0.3.33 — Project windows, live token speed, and quieter host status

## Windows

- **Open a project in its own window.** Right-click a project card and choose
  "Open in New Window". The new window lists only that project, with its own
  chat selection, transcript, terminals and panes. While it is open the main
  window hides the project; closing the window, or "Return to Main Window" in
  its menu, hands it back. Settings, About and update checks stay with the
  main window, and the Dock badge still counts every window.

## Chats

- **See token speed while a Pi chat works.** The trailer under a running turn
  now reads "Thinking… 1m 12s · ↓ 3.4k tokens · 52 tok/s". The rate is an
  estimate over the last few seconds, corrected by each message's reported
  usage. Providers that stream only a thinking summary (Claude, OpenAI
  Responses, Gemini) read low while thinking.
- **Long silent thinking no longer loses the Working spinner.** A turn that
  looked finished was parked after 2 minutes without stream output; the wait
  is now 5 minutes. Open tool calls and questions still hold it off entirely.

## Projects

- **A project's host shows only when it can't be reached.** The always-green
  presence dot on every project card is gone. An offline host now shows a
  slashed cloud with a tooltip naming the device. The device picker and rail
  keep their presence dots.

## Notifications

- **Badges no longer count sessions you've already read.** Sessions read
  before badges tracked what you'd seen, and subagent sessions Home never
  lists, could stay counted forever. Badges now drop every session already
  read, and a subagent counts as read when its parent session is.

Cut at build 1 on both desktop platforms. Pi Runtime stays at 0.87.1.3; iOS
stays at 0.2.0 (19).
