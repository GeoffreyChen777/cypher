# Cypher 0.3.52 — Translated steps, Shift for the original, and a lighter window

## Translation

- **Translate the agent's steps too.** With translation on, only the final
  answer used to be translated; what the agent says between tool calls
  ("Let me check the config first") stayed in its working language. A new
  "Steps between tool calls" switch on the Translation settings card (off
  by default, since every step costs a request to the translation model)
  translates those statements in the background. The agent never waits for
  them; each lands in place as it arrives. Needs Pi Runtime 1.1.0.5.
- **Hold Shift to see the original.** The "Show original" toggles above
  every translated part, and the separator rule, are gone. A translated
  message shows its translation; hold Shift over it and a glass toggle
  appears under the pointer, and Shift-clicking switches the whole message
  between the translation and the agent's own words. Replace mode can now
  show the original too. The toggle only appears after Shift is held on its
  own for a moment, so typing capitals never raises it.

## Chats

- **Fold chevrons line up with the text.** The chevrons on thought,
  work-run and tool-group toggles and on the files-changed card lose their
  tinted tile and sit flush with the text column.

## Performance

- **Less work while a session runs.** Spinners and loaders now repaint
  over the transcript, sidebar and composer instead of rebuilding them on
  every tick. With one session running a tool, the release build does
  about 40% less work at the same frame rate.

Cut at build 1 on both desktop platforms. Pi Runtime moves to 1.1.0.5
(background step translation), published after the desktop release; older
apps run it unchanged. iOS stays at 0.2.0 (29).
