# Cypher 0.3.45 — See which model actually answered

## Chats

- **See the model that actually answered each turn.** A relay or the
  Claude Code CLI can serve a different model than the one you picked, and
  Cypher never said so. Hovering a reply now shows the model that wrote it,
  after the timestamp. When it isn't the one you picked, the name turns
  amber with a warning icon and says what was requested. A dated snapshot,
  a `[1m]` variant, a provider prefix or a difference in case counts as the
  same model and isn't flagged. Replies from before this release show
  nothing.
- **"Tool calls shown per group" is exact.** A run one call over the limit
  used to show every call, so with the default of 5 a six-call run never
  folded. One call over now folds too, along with the thinking before it.

## Pi Runtime 1.0.1.4

- **The served model is recorded on every route.** For OpenAI Responses
  (including ChatGPT/Codex and Azure) and for Claude through the bridge, Pi
  didn't record which model the provider served, so a substitution there
  couldn't be shown. This Runtime records it. Devices on 0.3.38 or newer
  pick it up on their own; the model shows once the app is on 0.3.45.

macOS ships at build 1. Linux ships at build 2: build 1 never built,
because Docker Hub's sign-in for GitHub's runners failed on 2026-10-09 and
every pull of the `ubuntu:20.04` build container was refused. Build 2 is the
same code, pulling the same image (identical digest) from AWS's public
mirror. The shared channel for older clients stays on 0.3.43 until a version
ships at build 1 on both platforms. Pi Runtime moves to 1.0.1.4, published
after the desktop release; iOS stays at 0.2.0 (25).
