# Cypher 0.4.2 — Asking another workspace works

## Workspaces

- **Connections answer again.** Asking a connected workspace a question
  failed every time with "Invalid arguments: unknown field
  `_toolCallId`". The question now reaches the other workspace and its
  answer comes back.

## Devices

- **No stale updates.** The app checks for device updates once per
  launch, so a Linux device that updated itself afterwards, through
  auto-update or `cypher update`, kept its "X available" row. The row
  now goes away once the device runs that release.

## Linux

- Linux skipped 0.4.1, whose build GitHub's runners couldn't finish, so
  this release also brings it 0.4.1's changes: the workspace chat reaches
  your MCP servers, searches the web, asks you questions and takes
  `/scripts`, like a session. See [0.4.1](0.4.1.md).

Cut at build 1 on both desktop platforms. iOS stays at 0.4.0 (44) and Pi
Runtime at 1.5.2.1.
